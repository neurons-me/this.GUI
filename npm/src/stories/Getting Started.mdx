# .GUI Storybook
#### Composable, Declarative and Imperative.


### Getting Started
🌐 **window.GUI**
  Use this if you want the simplest possible setup:
  just drop a `<script>` tag in an HTML file and mount an app.

  Add this script to your HTML:

  ```html
  <div id="root"></div>
  <script src="https://cdn.jsdelivr.net/npm/this.gui@latest/dist/this.gui.bootstrap.umd.js"
    crossorigin="anonymous"></script>
  ```
  Then you can use the global `window.GUI` object:  

### Example:

```html
<script>
  (async function () {
    // 1) Ensure `.GUI` runtime + deps are loaded.
    //    After this resolves, you can safely call `window.GUI.mount(...)`.
    await window.GUI.bootstrap();

    // 2) Grab the root node where the app will mount.
    const root = document.getElementById('root');

    // 3) Build a declarative `.GUI` spec (JSON).
    const app = {
      type: 'Page',
      props: {
        title: '.GUI Bootstrap',
        subtitle: 'HTML setup.',
      }
    };

    // 4) Mounts to a chosen node.
    window.GUI.mount(app, root); // renders into the DOM
  })();
</script>
```

⬇️ **View Full HTML Example:**  <a href="/examples/bootstrap.html" download>Bootstrap</a>

## ⚡ Imperative

```js
const button = window.GUI.Button(); // builds a GuiNode (does NOT render yet)
window.GUI.mount(button, root);      // renders into the DOM
```

You are **executing commands** directly:

- “create a button”
- “mount this app here”
- “run now”

Imperative = **do this**.

---


## 🧩 Declarative

```js
{
  type: "Layout",
  children: [
    { type: "Button", children: ["Save"] }
  ]
}
```

You are not executing anything — you are **describing what should be rendered**:

- “I want a layout”
- “I want a button inside”

Declarative = **this is what it should look like**.

---

## 🧱 Composable

This is the **React environment**:

```jsx
<Layout>
  <Page>
    <Button />
  </Page>
</Layout>
```

Here you are composing live building blocks:

- components + hooks
- providers + state
- routing + context

Composable = **building blocks in a live runtime**.
