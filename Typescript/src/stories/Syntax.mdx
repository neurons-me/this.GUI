# Syntax — .GUI Storybook

This Storybook is your playground to explore and build with **.GUI**.

`.GUI` is a **declarative UI framework**. Instead of writing React code directly, you describe your UI as structured data (a spec), and `.GUI` renders it for you.

## 1. The Basics: UI as Data

Every screen is defined as a `spec` — a simple JavaScript object:

```ts
const spec = {
  type: 'Page',
  props: {
    title: 'My Dashboard'
  },
  children: [
    // your components go here
  ]
};
```

type tells `.GUI` which component to use.

props configures it.

children lets you nest other components.

## 2. Your First Screen

Try this simple example:

```ts
const spec = {
  type: 'Page',
  props: { title: 'Welcome' },
  children: [
    {
      type: 'Typography',
      props: { variant: 'h4', children: 'Hello from .GUI' }
    },
    {
      type: 'Button',
      props: {
        label: 'Click me',
        variant: 'contained',
        color: 'primary'
      }
    }
  ]
};

GUI.mount(spec, '#root');
```

## 3. Available Building Blocks

.GUI comes with a set of ready-to-use components:

- Layout: Page, Box, Paper, Stack, Grid
- Content: Typography, Card, Divider
- Interactive: Button, TextField, Switch, Checkbox
- Feedback: Alert, Spinner, Progress

## 4. Make it Dynamic (with .me)

You can connect any prop to live data using the read token:

```ts
{
  type: 'Typography',
  props: {
    variant: 'h5',
    children: { read: 'me.profile.name' }
  }
}
```

For actions:

```ts
{
  type: 'Button',
  props: {
    label: 'Save',
    onClick: { write: 'me.profile.save()' }
  }
}
```
